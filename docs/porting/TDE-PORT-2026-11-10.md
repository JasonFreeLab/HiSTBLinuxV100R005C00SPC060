## 2. 移植要点

- **HAL 选择**：Hi3798MV300 必须用 `adp/tde_v2_0`（SDK Makefile 判定；v1_0 为老芯片）。
  硬件：base `0xF8C10000`（映射 0x40a4）、IRQ = GIC **SPI91**（`TDE_INTNUM=123`）、SMMU `+0xF000`（首版 bypass）、
  时钟/复位 `PERI_CRG37 @0xF8A22094`（bit0 cken / bit4 srst）。
- **7.3 适配**（仅 `tde_osr_k.c`）：`DECLARE_TASKLET(…,0)` → 2 参数；tasklet 回调签名
  `(struct tasklet_struct *)`；导出函数表 `g_tde_export_funcs` + `EXPORT_SYMBOL_GPL`（供 PNG `__symbol_get`）。
- **port stubs（491 行）**：`HI_DRV_MMZ_Alloc/Release/Map/Flush`（dma_alloc_coherent + 表内同一 VA + `dma_sync_single_for_device(phys)`）、
  `/dev/hi_tde`（cdev+class+device、独立 dma 平台设备 `hi_tde_mmz`）、`osal_request_irq`（TDE_INTNUM→候选映射）、
  PROC/PM/`HI_GFX_*` 内存/寄存器映射、轮询完成 worker（无 IRQ 时 2ms）。
- **完成链**：DT 节点优先真实 IRQ（`of_irq_parse_and_map`，候选要求 `hwirq==123` 且 `chip != no_irq_chip`）；
  本内核 DT 无 TDE 节点 → 全候选 `no_irq_chip`，**自动降级 2ms 轮询完成**
  （`tde_poll_complete()`：读 `TDE_INT@0x504` → 清 `INTCLR@0x508=0x7` → `ListNodeComp/ListComp`），
  `request_irq` 成功则自动停止轮询。新增参数 `tde_irq_probe_only` / `tde_irq_off` / `tde_dbg` / `tde_irq_cnt`。
- **稳定性修复**：MMZ dma 设备重复注册（EEXIST/`sysfs_warn_dup`）、cleanup 顺序野指针（`TdeOsiListTerm` 前释放 window）、
  `free_irq` 与 request 不对称、vmalloc DMA WARN、卸载/重载 ×10 干净。

## 5. 已知限制（2026-11-11 修正版）

1. ~~**真实 IRQ 未启用**~~ **已修复（r8 / TDE v16p）**：GIC-only 映射 + 域就绪前延迟映射 + IRQ 成功后不启轮询；
   板端 `request_irq(39) ret=0`、`real IRQ active -> poll NOT started`、`tde_irq_cnt` 按 job 增长、`tde_poll_ticks` 恒 0。
   无需 DTS 节点（现网原生产 FIP 可用）。
2. ~~**SolidDraw 纯色 fill 不做 dst α 混合**~~ **已修复（TDE v16q, r9）**：实测确认 v2_0 fill opcode 不读 dst（
   QUICK/NORM_FILL 1/2OPT 均不混合，global/pixel alpha 只影响输出 alpha）。修复=驱动内用
   **1×1 预乘 ARGB8888 CLUT8 前景 + bResize 的 Bitblit（bg=dst）** 模拟 α 填充：CLUT[0] 存
   `alpha<<24 | premul(RGB)`（alpha = fillColor.a × globalAlpha/255），Bitblit 读 dst 完成 SRCOVER。
   需持久 coherent 缓冲（`tde_port_ctrl_alloc`）。板端验证：`tde_test` 的
   `SolidDraw alpha=128 (blend over dst)` PASS（输出 0x80089018，probe 12 组全 MIX）。
3. ~~**TDE_Rotate 未实现**~~ **已修复（v16r）**：用户态 `unf_tde.c` 实现 `HI_TDE2_Rotate`：
   180° 走 **HW Bitblit + enMirror=BOTH**（板端 PASS）；90°/270° 因 TDE v2 无 transpose 能力，
   由 API 内 **CPU fallback** 完成（mmz 映射缓存，4B 像素格式），板端 PASS。其余非 4B 格式返回
   `HI_ERR_TDE_UNSUPPORTED_OPERATION`；mask-rop/blend 仍受能力位图约束。
4. ~~**单矩形上限 4096×4095**~~ **已修复（v16r）**：`TdeOsiQuickCopy/TdeOsiSolidDraw/TdeOsiBlit` 入口检测
   `TDE_MAX_RECT_WIDTH/HEIGHT`，超限时自动按 tile 拆分并在同一 job 内提交多条命令（要求 src/dst 尺寸一致，
   否则返回 `HI_ERR_TDE_UNSUPPORTED_OPERATION`）。板端验证：**SolidDraw 5000×300** 与 **Bitblit 5000×300**
   均 PASS（跨 4096 宽度限制）。
5. ~~`--clut-hw` 比 CPU LUT 慢~~ **已修复主要瓶颈（PNG v18, r9）**：
   慢的主因不是 TDE 硬件，而是**每阶段 `pr_err` 打到串口 console**（每行约 7–10ms）。
   修复分三步：
   1) v18：CLUT2RGB/A2 的 verbose 打印改走 `PNG_DBG`（默认关）→ 163/203.7ms 降到 **5.3/45.1ms**；
   2) v19：temp 缓冲 **grow-only 缓存** + job1/job2 **合并为单 job**（一次 EndJob）→ warm **4.5/39.4ms**；
   3) v21：**原地分块展开**（源索引与 RGB 输出同缓冲、stride 不同：按 y0=ceil(y1·src/dst) 自底向上分块，
      仅 ~log3(h) 条命令、无 staging 拷贝）→ warm **3.8/34.4ms**，逐字节 MATCH；A2 子字节矩阵 7/7 MATCH。
   剩余差距（3.8 vs CPU 2.8ms；34.4 vs 28.9ms）来自 TDE 必须的第二次全图 DRAM 读写
   （读索引 2MB + 写 RGB 6.2MB @ 1080p），属硬件带宽下限；CPU LUT 在解码同 pass 内融合，故仍是最快默认路径。

## 8. v16 reload 加固（task-8：hi-accel restart 后 TDE 挂死）

**根因**：r4 `hi-accel.service` 的 `ExecStop` 未 rmmod `hi_tde`，而 `hi-accel-load.sh` 对已加载模块
`SKIP hi_tde` ⇒ `systemctl restart hi-accel` 后 TDE 仍是 boot 时旧实例（TdeOsi 队列 / INT / CRG37 /
轮询 work 状态保留），其它模块（含 mmz_shim）全部重载；随后 tde_test 的 job 挂死 → 30s 看门狗。
fresh boot 直接 tde_test PASS，符合该组合态问题。

**修复**：
1. 服务：`ExecStop=-/sbin/rmmod hi_tde`（放在 `hi_venc` 之后；补丁
   `work/tde/scripts/hi-accel.service.tde-stop.patch`）。restart 时真正卸载并重载 TDE。
2. 模块 v16（`hi_tde.ko` sha1 `1efdaba48f9de35cf8784f7f4a2fe1b12ad21754`）：
   - `port_stubs_init()`：ioremap TDE regs（0xf8c10000），打印
     `TDEDBG: tde regs[init-before] INT/INTCLR/CTRL/AQ_NADDR/STA`；
   - `tde_recover=1`（默认）：写 `INTCLR(0x508)=0x7`；对 `PERI_CRG37@0xf8a22094`
     执行 `cken=1 → srst=1(10µs) → srst=0` 复位脉冲，再清 INT，打印 `init-after` 快照；
     `tde_recover=0` 仅打印快照（对照定位）；
   - 轮询 work：新增 `tde_poll_ticks`（sysfs 0444）；`tde_dbg=1` 时每 500 tick（≈1s）打印
     `TDEDBG: poll alive ticks=...` + TDE 寄存器快照；poll 完成时打印 `poll completion ran`；
   - 既有 no-IRQ 2ms 轮询完成、`tde_irq_cnt`、`tde_irq_off`、`tde_irq_probe_only` 不变。

**使用/验证**：
```sh
insmod hi_tde.ko tde_dbg=1        # 看 init regs + recover 快照 + poll alive
systemctl restart hi-accel        # 需服务补丁，确保 hi_tde 被卸载重载
tde_test                          # 期望 PASS；tde_irq_cnt/tde_poll_ticks 增长
cat /sys/module/hi_tde/parameters/tde_poll_ticks
```
若仍挂：抓 `/proc/<pid>/stack`、dmesg 中 `tde regs[...]`/`poll alive`/`poll completion`、
`tde_irq_cnt`、`tde_poll_ticks`、串口全文（watchdog 前最后输出）。

### 8.1 最终结论（v16k，2026-11-11，board r5k 三项全绿）

v16 的"recover 快照 + 轮询"只是过渡；真正根因是**轮询完成与 clock-gated 寄存器窗口的冲突**：
TDE 完成链在空闲时 `TdeHalSetClock(FALSE)` 关时钟，2ms poll 仍读 `TDE_INT` → 总线 stall（最终整板 hang）。

**最终件 `hi_tde.ko` sha1 `9f1347fb68dd0f2c1349d731bda079d0da0dce3a`**：
- 新参数 `tde_keep_clock=1`（默认）：`adp/tde_v2_0/tde_hal_k.c` 的 `TdeHalSetClock(FALSE)` 变 no-op；
- `port_stubs_init()` 在 `TdeOsiListInit` 后显式 `TdeHalSetClock(HI_TRUE)`；cleanup `tde_keep_clock=0` 后再关时钟；
- `tde_port_clock_force_on()`（CRG37 always-on，写 bit0 + 回读确认）在 job 派发前与每次 poll 前调用（双保险）；
- 保留 `tde_recover=0`（默认，不再碰 TDE 窗口）、`tde_regs_dbg=0`、`tde_poll_ms`、active 门控（完整 cmd 比较）、
  ioctl/open/close/mempool/job_done 诊断；
- 补丁：`work/tde/patches/0001-tde_osr_k-7.3-tasklet-and-export.patch`、
  `work/tde/patches/0010-tde_hal_k-7.3-keep-clock.patch`。

**board 验收**：单加载 tde_test ×10 10/10 PASS；tde-only reload ×10 10/10 PASS（CmaFree 稳定）；
service 10× restart + 立即 tde_test 10/10 PASS。遗留：1080p PNG / pal8 `--clut-hw` 回归随 A1/B0 批次复测。
**环境**：rootfs 写坏 ko，模块经 `/dev/shm`（tmpfs）加载；正式磁盘安装待 rootfs 修复/过渡方案。
